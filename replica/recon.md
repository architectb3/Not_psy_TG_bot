# Recon map: Not Spy (@notspybot), бот Telegram

Scope: ядро бота. Подключение через Telegram Business, уведомления об удалённых и изменённых сообщениях, сохранение исчезающих медиа, команды управления. Без подписок, оплаты и рефералки.
For: личное использование владельцем. Один пользователь, не для распространения.
Date: 2026-10-12
Статус: согласовано (личный бот, 2026-10-12)

## Решения для личной версии

- Бот отвечает только владельцу (`OWNER_ID`). Остальным — короткий отказ.
- Нет пробного периода, тарифов, оплаты, рефералки, админки, рассылок.
- Только русский язык.
- Копии сообщений хранятся 30 дней (`RETENTION_DAYS`, можно поменять), потом удаляются.
- Mini App не делаем. История — командой в самом боте.
- Хостинг свой: VPS или домашний сервер, один процесс и файл SQLite.

## Core loop

Пользователь один раз подключает бота в Telegram Business. После этого бот
присылает ему всё, что собеседники удалили или изменили в личных чатах, и
сохраняет исчезающие фото и видео. У оригинала платят за продолжение после
пробных 7 дней. В личной версии этого нет.

## Как это работает технически

Бот подключается к аккаунту через Telegram Business (Настройки → Telegram
Business → Чат-боты). После этого Bot API шлёт ему:

- `business_connection` — подключение, отключение, права;
- `business_message` — каждое новое сообщение в личных чатах;
- `edited_business_message` — новая версия изменённого сообщения;
- `deleted_business_messages` — только ID удалённых сообщений, без текста.

Отсюда главное: чтобы показать удалённый текст, бот обязан сохранить
сообщение в момент получения. Заявление оригинала «не храним переписку»
с этим не сходится. Скорее всего, они хранят копию ограниченное время.
Нам нужно решить, сколько и как хранить (шифрование, срок жизни).

Ограничения: только личные чаты один на один. Группы и каналы бот не видит.
Истории до подключения у бота нет.

## Flows

```
F01 Подключение
    S01 -> принять -> S02 -> настройки Telegram (вне бота) -> S03
    happy path: ~7 нажатий (3 в боте, ~4 в настройках Telegram)
    edge: нет Premium; выдали бота без права читать сообщения;
          подключили к части чатов; отключили и подключили снова

F02 Собеседник удалил сообщение
    событие -> S04 (или S13, если удалили много)
    happy path: 0 нажатий
    edge: сообщение пришло до подключения; медиа больше лимита; альбом;
          удалили сообщение самого пользователя (не присылать)

F03 Собеседник изменил сообщение
    событие -> S05
    edge: несколько правок подряд; правка подписи у медиа

F04 Сохранить исчезающее медиа
    пользователь отвечает на одноразовое фото -> S06
    happy path: 1 действие в чате
    edge: ответил после просмотра (уже поздно); кружок/голос с таймером

F05 Купить подписку
    S07 -> S08 -> оплата -> S07 (активна)
    happy path: 3 нажатия
    edge: оплата отменена; возврат; продление поверх активной

F06 Пригласить друга
    S09 -> поделиться ссылкой -> друг /start по ссылке -> друг платит -> начисление
    edge: сам себя пригласил; друг уже был в боте

F07 Пробный период закончился
    S12 -> S08

F08 Настройки
    S07 -> S10 -> переключатель

F09 История в Mini App
    S07 -> S11 -> поиск/фильтр
```

## Out of scope (cannot or should not be cloned)

- Название «Not Spy», логотип, тексты бота и сайта. Только свой бренд и свои слова.
- Их пользователи и партнёрская сеть.
- Работа без Premium через вход в аккаунт пользователя (userbot, MTProto-сессия).
  Это доступ к чужому аккаунту целиком, риск блокировки и утечки. Не делаем.
- Обход защиты от скриншотов и пересылки сверх того, что отдаёт Bot API.
- Двухуровневая денежная рефералка с выводом денег. Технически можно, но это
  финансовые обязательства и налоги. Предлагаю начать с бонусных дней.

## Риски, которые надо знать до старта

- **Чужие персональные данные.** Бот сохраняет сообщения собеседников без их
  ведома. В РФ это 152-ФЗ, в ЕС — GDPR. Нужны политика конфиденциальности,
  короткий срок хранения, шифрование и честный текст о том, что хранится.
- **Правила Telegram.** Бот подпадает под Terms of Service for Bots и правила
  Telegram Business. Если Telegram поменяет поведение исчезающих медиа или
  Business API, часть функций может перестать работать.
- **Premium.** Не до конца ясно, нужен ли пользователю Premium для
  подключения бизнес-бота сейчас. Источники расходятся. Проверим на живом
  аккаунте.
- **Медиа после удаления.** Не проверено, остаётся ли `file_id` рабочим после
  удаления у собеседника. Надёжнее сразу копировать медиа в своё хранилище.
